# Prototipos

Referencia visual de las pantallas de la versión 1.0. Las capturas de `capturas/` muestran cómo debe verse cada una. Los archivos `.dc.html` son las fuentes: contienen los textos, los datos de ejemplo y los tokens de color, y necesitan `support.js` en la misma carpeta.

Para verlas en el navegador, desde esta carpeta: `npx serve .` y abrir la dirección que indica.

| --- | --- |
| Main.dc.html | P-07 Home de gestión (web) |
| Propiedad.dc.html | P-16 Ficha del bien (web) |
| Obligaciones.dc.html | P-26 Obligaciones (web) |
| FinDeMes.dc.html | P-48 Completar gastos del mes (web) |
| ResumenDeposito.dc.html | P-34 Resumen de depósito (web) |
| FichaPropietario.dc.html | P-12 Ficha del propietario (web) |
| IngresoApp.dc.html | P-02 Ingreso (app) |
| HomeApp.dc.html | P-07 Home de gestión (app) |
| PagoApp.dc.html | P-28 Registrar pago (app) |

Los prototipos muestran el selector de idioma (ES/EN/PT) solo como referencia: en la versión 1.0 queda oculto.
